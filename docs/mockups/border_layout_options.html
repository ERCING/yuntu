边框 / 标题 / 色标布局方案（用于 --decorations）

你看完直接回我选 A/B/C/D。目标：减少右侧空白、信息更好读、画面更干净。

A

紧凑右侧色标（外置但不挤占画面）

保持“右侧竖色标”习惯，但把主图拉满到右侧，只留一个很窄的色标槽；底部信息条保留。

B

底部横向色标（最大化画面宽度）

完全取消右侧色标，改为底部横向色标；底部做一条“信息栏”：左标题、中时间、右范围。

C

内嵌色标（画布最紧凑）

色标放到图内侧右边缘（半透明底），不增加画布尺寸；信息文本也放图内侧角落，整体最“干净”。

D

右侧信息栏（色标 + 元数据堆叠）

固定一个窄右栏：上部显示范围/类型，中部竖色标，底部时间；主图永远对齐、观感更“规整”。

选择建议：
如果你希望尽量保持现有风格但去掉“右侧挤压/留白”，选 A；
如果你希望画面最满、阅读最舒服，选 B；
如果你希望最紧凑、最像“业务图叠加层”，选 C；
如果你希望右侧信息规整对齐、模板化输出，选 D。
